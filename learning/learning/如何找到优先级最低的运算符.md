用具体例子说明在有多个括号时如何找到主运算符。核心是使用括号计数器（`paren_count`）来跟踪是否在括号内。

## 核心机制：括号计数器（paren_count）

看代码第228-242行：

```c
int paren_count = 0;  // 括号计数器

for (int i = p; i <= q; i++) {
  if (tokens[i].type == '(') {
    paren_count++;    // 遇到左括号，计数器+1
    continue;
  } else if (tokens[i].type == ')') {
    paren_count--;    // 遇到右括号，计数器-1
    continue;
  }
  
  // 括号内的运算符不考虑（跳过）
  if (paren_count > 0) {
    continue;  // 在括号内，跳过这个运算符
  }
  
  // 只有括号外的运算符才考虑作为主运算符
  ...
}
```

原理：
- `paren_count = 0`：在括号外
- `paren_count > 0`：在括号内
- 遇到 `(` 时 `paren_count++`
- 遇到 `)` 时 `paren_count--`

## 例子1：简单嵌套括号

表达式：`"5 + (3 * 2) - 1"`

假设tokens数组：
```
[0] {type: TK_NUM, str: "5"}
[1] {type: '+', str: "+"}
[2] {type: '(', str: "("}
[3] {type: TK_NUM, str: "3"}
[4] {type: '*', str: "*"}
[5] {type: TK_NUM, str: "2"}
[6] {type: ')', str: ")"}
[7] {type: '-', str: "-"}
[8] {type: TK_NUM, str: "1"}
```

### 找主运算符的过程：

```
扫描 tokens[0..8]:

i=0: tokens[0] = "5" (数字，跳过)
i=1: tokens[1] = "+" 
     paren_count = 0 (在括号外)
     优先级 = 2
     候选主运算符: + (位置1, 优先级2)

i=2: tokens[2] = "("
     paren_count++ → 1 (进入括号)

i=3: tokens[3] = "3" (数字，跳过)
i=4: tokens[4] = "*"
     paren_count = 1 (在括号内！)
     → continue (跳过，不参与主运算符选择)

i=5: tokens[5] = "2" (数字，跳过)
i=6: tokens[6] = ")"
     paren_count-- → 0 (退出括号)

i=7: tokens[7] = "-"
     paren_count = 0 (在括号外)
     优先级 = 2
     候选主运算符: - (位置7, 优先级2)
     因为优先级相同，选择最右边的 → 主运算符更新为 - (位置7)

i=8: tokens[8] = "1" (数字，跳过)

最终主运算符: - (位置7)
```

结果：主运算符是 `-`（位置7）

为什么不是 `*`？因为它在括号内，会被递归处理。

i=8: tokens[8] = "-"
     paren_count = 1 (在括号内！)

最终主运算符: * (位置5)

为什么不是 `+` 或 `-`？因为它们都在括号内。

## 例子3：嵌套括号

表达式：`"4 + 3 * (2 - (1 + 1))"`

tokens数组（简化表示）：
```
[0] "4"
[1] "+"
[2] "3"
[3] "*"
[4] "("
[5] "2"
[6] "-"
[7] "("
[8] "1"
[9] "+"
[10] "1"
[11] ")"
[12] ")"
```

### 找主运算符的过程：

```
扫描 tokens[0..12]:

i=0: "4" (数字，跳过)
i=1: "+"
     paren_count = 0
     优先级 = 2
     候选: + (位置1, 优先级2)

i=2: "3" (数字，跳过)
i=3: "*"
     paren_count = 0
     优先级 = 3
     优先级更高，不更新主运算符

i=4: "("
     paren_count++ → 1

i=5: "2" (数字，跳过)
i=6: "-"
     paren_count = 1 (在括号内！)
     → continue (跳过)

i=7: "("
     paren_count++ → 2 (嵌套括号)

i=8: "1" (数字，跳过)
i=9: "+"
     paren_count = 2 (在嵌套括号内！)
     → continue (跳过)

i=10: "1" (数字，跳过)
i=11: ")"
     paren_count-- → 1 (退出内层括号)

i=12: ")"
     paren_count-- → 0 (退出外层括号)

最终主运算符: + (位置1)
```

结果：主运算符是 `+`（位置1）

为什么不是 `*`、`-` 或内层的 `+`？因为它们都在括号内，会被递归处理。

## 可视化理解

用括号深度来理解：

```
表达式: "4 + 3 * (2 - (1 + 1))"

括号深度:
4 + 3 * ( 2 - ( 1 + 1 ) )
0 0 0 0 1 1 1 2 2 2 2 1 0
        ↑     ↑     ↑
        外层括号  内层括号

主运算符选择:
- 只考虑深度为0的运算符
- 深度0的运算符: + (位置1), * (位置3)
- 优先级: + (2) < * (3)
- 主运算符: + (优先级最低)
```

## 关键点总结

1. 括号计数器跟踪当前是否在括号内
   - `paren_count = 0`：括号外
   - `paren_count > 0`：括号内

2. 只考虑括号外的运算符
   - 括号内的运算符会被递归处理
   - 遇到 `(` 时 `paren_count++`
   - 遇到 `)` 时 `paren_count--`

3. 嵌套括号的处理
   - 每层括号都会增加计数器
   - 只有所有括号都关闭（`paren_count = 0`）时，运算符才参与主运算符选择

4. 算法流程
   ```
   遍历每个token:
     如果是 '(' → paren_count++
     如果是 ')' → paren_count--
     如果是运算符:
        如果 paren_count > 0 → 跳过（在括号内）
        如果 paren_count == 0 → 考虑作为主运算符候选
   ```
