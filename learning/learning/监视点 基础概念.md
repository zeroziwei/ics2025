## 监视点的基本概念

**什么是监视点？**
监视点用于监控表达式的值，当值变化时暂停程序执行。

**在代码中的体现：**
查看 `watchpoint.c` 第20-28行的 `WP` 结构体：

```20:28:nemu/src/monitor/sdb/watchpoint.c
typedef struct watchpoint {
  int NO;
  struct watchpoint *next;
  
  /* TODO: Add more members if necessary */
  char expr[256];  // 监视的表达式
  word_t old_val;  // 表达式的旧值

} WP;
```

**结构体字段说明：**
- `NO`: 监视点编号，用于标识和删除
- `next`: 链表指针，支持多个监视点
- `expr[256]`: 存储要监视的表达式字符串（如 `"$pc"` 或 `"*0x80000000"`）
- `old_val`: 存储表达式的旧值，用于与新值比较

**工作原理：**
1. 用户设置监视点（如 `w $pc`）
2. 系统记录表达式和初始值
3. 每条指令执行后重新计算表达式, 也就是说他依附于表达式求值咯
4. 若新值 ≠ 旧值，触发并暂停程序

**与GDB的对比：**
- GDB: `watch variable_name` 或 `watch *0x12345678`
- NEMU: `w $pc` 或 `w *0x80000000`
