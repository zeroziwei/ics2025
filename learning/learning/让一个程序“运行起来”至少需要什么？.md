查看代码，确认最简单的运行时环境（TRM）需要哪些部分：


## 最简单的运行时环境需要什么？

文章中的答案：
> "只要有内存, 有结束运行的方式, 加上实现正确的指令, 就可以支撑最简单程序的运行了"

用代码具体说明：

## 1. 内存（Memory）

程序必须在内存中才能执行。

```c
// 程序需要内存来存放：
// - 代码（.text段）
// - 数据（.data段）
// - 未初始化数据（.bss段）
// - 栈（stack）
// - 堆（heap，可选）
```

## 2. 结束运行的方式（Exit Mechanism）

这是核心需求之一。没有它，程序无法正确结束。

```c
// trm.c
void halt(int code) {
  nemu_trap(code);  // 通过特殊指令告诉NEMU程序结束了
  while (1);
}
```

作用：
- 告诉系统程序已完成
- 传递退出码给NEMU
- 让NEMU从执行循环中退出

## 3. 正确的指令实现

NEMU需要能执行程序的指令，这是硬件层面的要求。

---

以上是理论上的最小需求。但要让一个C程序真正运行起来，还需要更多基础设施：

## 实际上还需要（从代码看）

### 4. 程序入口点（Entry Point）

程序需要明确的开始位置：

```asm
# start.S
_start:
  mv s0, zero
  la sp, _stack_pointer    # 设置栈指针
  call _trm_init           # 调用初始化
```

为什么需要？
- CPU不知道从哪里开始执行
- 链接器通过 `ENTRY(_start)` 告诉系统入口点

### 5. 栈（Stack）

函数调用需要栈：

```asm
la sp, _stack_pointer    # 设置栈指针到正确位置
```

为什么需要？
- C函数调用需要栈来保存局部变量、返回地址等
- 没有栈，无法调用 `main()` 函数

### 6. 初始化函数（_trm_init）

连接启动代码和用户程序的桥梁：

```c
// trm.c
void _trm_init() {
  int ret = main(mainargs);  // 调用用户的main函数
  halt(ret);                 // main返回后结束程序
}
```

为什么需要？
- 提供从启动代码到 `main()` 的调用路径
- 处理 `main()` 的返回值并正确结束

### 7. 堆（Heap，可选但很重要）

虽然简单程序可能不需要，但TRM提供了：

```c
// trm.c
Area heap = RANGE(&_heap_start, PMEM_END);
```

作用：
- 为程序提供动态内存分配的区域
- 程序可以使用 `malloc()`（如果实现了）

---

## 总结：分层理解

### 最简化的理解（文章中的答案）：

```
运行时环境 = 内存 + 结束方式 + 指令支持
```

### 实际实现（代码中的实现）：

```
运行时环境 = 
  ├─ 内存（程序存放和执行的地方）
  ├─ 入口点（start.S: _start）
  ├─ 栈（用于函数调用）
  ├─ 初始化（_trm_init）
  ├─ 结束方式（halt）
  └─ 堆（heap，可选但通常提供）
```

## TRM提供的4个核心API

从AM的角度看，TRM只需要4个API：

```c
// 1. 堆区
Area heap;              // 堆的起始和末尾

// 2. 输出字符（虽然是最简运行时环境，但AM把它包含进来了）
void putch(char ch);

// 3. 结束程序
void halt(int code);

// 4. 初始化
void _trm_init();
```

其中，对于最简单的程序（如 `dummy.c`）：
- `heap`：可以不用
- `putch()`：可以不用
- `halt()`：必须
- `_trm_init()`：必须（它调用了main）

## 对比：有vs没有运行时环境

### 没有运行时环境：
```
CPU启动 → ??? → 执行指令 → ??? → 结束?
        ↑                ↑
      入口在哪？      如何结束？
```

### 有运行时环境（TRM）：
```
CPU启动
  ↓
_start (start.S)          ← 入口点
  ↓
设置栈指针                ← 栈准备好了
  ↓
_trm_init()              ← 初始化
  ↓
main()                   ← 你的程序
  ↓
halt()                   ← 正确结束
```
