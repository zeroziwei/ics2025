## 问题：`"1 + 2 + 3"` 有两个 `+`，主运算符是哪一个？

答案：主运算符是右边的 `+`（第二个 `+`）

---

## 代码中的处理逻辑

看代码第266-270行：

```c
// 选择优先级最低的（最后计算），如果优先级相同，选择最右边的
if (priority <= min_priority) {
  min_priority = priority;
  main_op = i;  // 不断更新main_op，最后保留的是最右边的
}
```

关键点：
- 使用 `<=` 而不是 `<`
- 从左到右扫描，遇到相同优先级时不断更新 `main_op`
- 最终保留的是最右边的运算符

```
最终主运算符: + (位置3，右边的+)
```

## 为什么同优先级时，右边的运算符是主运算符？

### 1. 结合性（Associativity）

对于 `+` 和 `-`，是左结合（left-associative）：
```
1 + 2 + 3  =  (1 + 2) + 3  =  3 + 3  =  6
```

计算顺序：
- 先算 `1 + 2 = 3`
- 再算 `3 + 3 = 6`

最后一步是右边的 `+`，所以它是主运算符。

### 2. 递归分裂的逻辑

如果主运算符是右边的 `+`（位置3）：
```
分裂:
  左边: tokens[0..2] = "1 + 2"
  右边: tokens[4] = "3"
  
递归计算左边: eval(0, 2) → "1 + 2" → 3
递归计算右边: eval(4, 4) → "3" → 3
最终: 3 + 3 = 6  ✓ 正确！
```

如果主运算符是左边的 `+`（位置1）：
```
分裂:
  左边: tokens[0] = "1"
  右边: tokens[2..4] = "2 + 3"
  
递归计算左边: eval(0, 0) → "1" → 1
递归计算右边: eval(2, 4) → "2 + 3" → 5
最终: 1 + 5 = 6  ✓ 也正确！

等等，这个结果也对？
```

实际上，对于加法，两种分裂方式结果相同（因为加法满足结合律）。但为了保持一致性，我们选择右边的运算符作为主运算符。

### 3. 为什么选择右边？——减法的情况

看减法：`"10 - 5 - 2"`

如果主运算符是右边的 `-`：
```
分裂:
  左边: tokens[0..2] = "10 - 5" → 5
  右边: tokens[4] = "2"
最终: 5 - 2 = 3  ✓ 正确！(10-5-2 = 3)
```

如果主运算符是左边的 `-`：
```
分裂:
  左边: tokens[0] = "10"
  右边: tokens[2..4] = "5 - 2" → 3
最终: 10 - 3 = 7  ✗ 错误！(应该是3，不是7)
```

所以对于减法，必须选择右边的 `-` 作为主运算符。

## 可视化理解

### 表达式树的角度

`"1 + 2 + 3"` 的正确解析树：

```
        +
       / \
      +   3
     / \
    1   2
```

最后计算的运算符是根节点的 `+`（右边的 `+`）。

如果选择左边的 `+` 作为主运算符：

```
        +
       / \
      1   +
         / \
        2   3
```

虽然结果相同，但不符合左结合的习惯。

## 代码实现的巧妙之处

看代码第267行：
```c
if (priority <= min_priority) {  // 注意是 <= 不是 <
```

为什么用 `<=` 而不是 `<`？

- 如果只用 `<`：遇到相同优先级时不会更新，会保留第一个运算符
- 使用 `<=`：遇到相同优先级时会更新，最终保留最后一个（最右边的）运算符

这正好符合左结合的要求。

## 关键理解点总结

1. 结合性：`+`、`-`、`*`、`/` 都是左结合的
   - `a + b + c` = `(a + b) + c`
   - 最后计算的是右边的运算符

2. 代码实现：使用 `<=` 而不是 `<`
   - 相同优先级时不断更新 `main_op`
   - 最终保留最右边的运算符

3. 为什么重要？
   - 对于减法/除法，选择错误的运算符会导致错误结果
   - 保持一致性，所有左结合运算符都选择右边的

4. 递归分裂的正确性
   - 选择右边的运算符作为主运算符
   - 左边包含所有左边的运算，右边是最后一个操作数
   - 这样递归计算才能得到正确结果

## 一个思考题

对于表达式 `"8 / 4 / 2"`：
- 主运算符应该是哪个 `/`？
- 如果选择左边的 `/` 会得到什么结果？
- 如果选择右边的 `/` 会得到什么结果？

答案：
- 主运算符应该是右边的 `/`（位置...）
- 选择左边的 `/`：`8 / (4/2) = 8 / 2 = 4` ✗ 错误
- 选择右边的 `/`：`(8/4) / 2 = 2 / 2 = 1` ✓ 正确

这进一步说明了为什么必须选择右边的运算符作为主运算符。
